## Context

We set ten typeface combinations on real components of the site — from a dot-matrix scoreboard to a 1970s
match poster — and tried each one across every page.

## Decision

We keep the current set:

| Role | Typeface |
| :-- | :-- |
| Headlines | Bricolage Grotesque |
| The word that changes the tone | Instrument Serif Italic |
| Text | Geist |
| Labels and data | Geist Mono |

One typeface system on every view. The README images embed the same fonts, so the organisation profile
reads like the website.

## Consequences

The type lab and its switcher are gone, along with the thirty-six fonts they loaded.
